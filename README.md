# phat-beatiful
Don't let the name fool you - a last ditch, bare bones effort using python code to make use of a Pimoroni Phatbeat,<br> ignoring the led's completely and hijacking the buttons to 
navigate an existing playlist consisting of 6 internet radio stations before everything ends in the trash. <br>
For Best Results - use strictly on **DietPi OS** to avoid long bootups and resource conflicts.  Pi OS is ok for minimal barebones barebuttons.py and flask_web.py only though. <br>
**Pre-requisites:** <br> Install Dietpi OS or Raspbian lite OS, MPD(installs Alsa), MPC, with a working mpd.conf, GPIO libraries, Python and Utilities, <br> 
Optional:  RPIMonitor, Squeezelite and an MPD Client. <br>
If using the web interface, webserver such as nginx or lightppd is required. <br> To use Flask web page, you need to install Flask with Pip in a virtual environment, along with Tornado, Sqlalchemy and gpizero. <br> Barebones web page is included in flask_web.py script. <br>
**You may not see an annoying LED ever again!**. <br>  But everyonce in a while, you may see some pirate ghosts on the led panel. The web page runs at port 5000 for testing and can be gussied up a bit to your choosing.
Barebuttons1a.py will handle all the physical buttons on the phat itself.<br>  For an EXTRA web interface, demo_iframe.html and index.html will generate a wrapper for the web page generated by flask_web.py, which uses port 5000 or a port of your choice after testing.<br>
A bash script will store demo_iframe and index.html in /var/www (dietpi) <br>
- Purely optional, but the combination of demo_iframe and index.html will demo extra configuration possibilities - . <br>
**Note: ** Some early PhatBeats have extra small buttons, so the web page option will assist those without dainty attributes. <br>
If  you don't have a Pimoroni PhatBeat board, ignore the barebuttons1a.py - but feel free to use the flask_web.py for your chuckles. <br>
**-OR-BETTER-YET-** if you have 6 buttons lying around just waiting to be used...go have at it.<br>
