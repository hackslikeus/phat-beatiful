# phat-beatiful
don't let the name fool you - a last ditch, bare bones effort using python code to make use of a Pimoroni Phatbeat, ignoring the led's completely and hijacking the buttons to 
navigate an existing playlist consisting of 6 internet radio stations before everything ends in the trash.
Pre-requisites: Dietpi or Raspbian lite OS, MPD, MPC with a working .conf, GPIO libraries, Python and Utilities, Alsa
To use Flask web page, you need to install Flask with Pip in a virtual environment, along with Tornado.  Barebones web page is included in flaskhtml.py script.
You will not see an annoying LED ever again.
